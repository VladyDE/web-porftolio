# Data Engineer Portfolio

Static bilingual portfolio built with Astro, TypeScript, and custom CSS.

## Commands

```bash
npm install
npm run dev
npm run build
```

Edit `src/data/portfolio.ts` to replace the sample content and links. Replace the placeholder SVG files in `src/assets/` with your real portrait, project screenshots, and certification logos. Update the production URL in `astro.config.mjs` before publishing.
